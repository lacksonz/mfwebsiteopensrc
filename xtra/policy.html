1. what we collect the short version

xtra stores as little as it can get away with. mostly discord ids, not personal details, and almost nothing about you unless you interact with a feature that needs it.

we don't collect emails, ip addresses, payment details, or anything from outside discord. we don't run ads or sell data to anyone, full stop.

2. message content the message content intent

xtra reads message text for a small number of specific features, and only while those features are turned on:

  • text commands — commands typed with a prefix like !kick instead of a slash command. we're removing this feature on 4 november 2026, at which point xtra stops needing to read ordinary messages at all.
  • automod — a server admin can turn on filters for invite links, spam, mass mentions or shouting. this only runs in servers where an admin has explicitly enabled it.
  • word chain and afk detection — checking whether a message continues a word chain game, or whether someone who marked themselves away has spoken again.
what we don't do: we don't log, store, or review ordinary conversation. message text is read in memory to check the rules above and then discarded. it is never written to a database or sent anywhere outside that one check.

an exception is the edit and delete log, which is opt-in per server: if enabled, the before/after text of an edited or deleted message is posted to a channel your server's own staff chose, so they can moderate their own server. that's the only case where message text is retained, and it's retained by your server's log channel, not by us separately.

3. ai features chat, vision, captions, tts

commands like /chat, /see, /aicaption and the text-based ai tools send what you type, and any image you attach, to Groq, our ai inference provider, in order to generate a reply. this is the same as pasting your message into any ai chat tool.

conversation history for /chat is kept in memory per channel so the bot can hold a conversation, capped at a small number of recent messages, and is wiped whenever you run /reset, whenever xtra restarts, or automatically once the cap is exceeded. it is not saved to disk.

text-to-speech commands (/tts, /vctts, soundboard) send the text you provide to Microsoft's Edge text-to-speech service to generate audio. no account or personal data is attached to that request beyond the text itself.

none of this data is used to train any model, ours or anyone else's.

4. voice features

xtra can join a voice channel to speak a message aloud (/vctts) or play a short sound (/soundboard). it does not listen to, record, or transcribe anything said in a voice channel. it joins only when a command is run, plays the requested audio, and does not otherwise process voice data.

if voice moderation or recording is added in the future, it will be off by default per server, require an explicit opt-in from that server's admins, and announce itself audibly whenever it's active. this policy will be updated before any such feature ships.

5. where data lives

settings (prefixes, autorole, automod rules, log channel, jail configuration, starboard settings) and the blacklist are stored on our hosting provider and persist across restarts. warnings and moderator stats are kept in memory by default and clear on restart, unless your server's owner has enabled longer persistence, in which case they're stored the same way as settings.

nothing is backed up to a third-party analytics or storage service. we don't use tracking cookies, pixels, or third-party ad networks on our website.

6. who else sees it

data is visible to:

  • the bot's operator, for running and maintaining the service, and for responding to abuse reports
  • your own server's staff, for anything posted to a log channel or dashboard your server chose to set up
  • groq and microsoft, for the specific ai and tts requests described above, governed by their own privacy terms

we do not sell, rent, or otherwise share your data with advertisers or unrelated third parties.

7. your choices

  • reset your ai memory anytime with /reset
  • see your warnings with /mod warnings or the prefix equivalent
  • ask a server admin to clear your warnings, remove you from a blacklist, or turn off a feature entirely
  • ask us directly to delete data tied to your user id across every server the bot is in — see the contact section below

removing the bot from a server does not automatically erase that server's stored settings; ask us if you'd like that data cleared too.

8. age requirement

xtra follows discord's own terms of service, which require users to be at least 13, or the minimum age in their country if higher. we don't knowingly collect data from anyone below that age beyond what discord itself already requires to hold an account.

9. changes to this policy

if this policy changes in a way that matters, the "last updated" date at the top will change and, where practical, we'll note it in the bot's server. continuing to use xtra after an update means you accept the current version.

10. contact

Contact XtraSupport@proton.me if you have any issues or want your data deleted.
